隱私權政策

適用應用程式：FAR 商品圖片同步
更新日期：2026 年 11 月 20 日

本政策說明 FAR 商品圖片同步及相關商品試算表同步功能如何處理資料。管理者為 An Chen，聯絡信箱：iwant2b1234@gmail.com。

1. 處理哪些資料

  • 使用者上傳的商品圖片、檔案名稱、圖片格式及圖片連結。
  • 應用程式建立或經使用者明確授權使用的特定 Google Drive 檔案識別資料，以及其連結讀取權限。
  • 供背景同步使用的 Google OAuth 授權憑證，以及同步狀態與錯誤資訊。
  • 在另外授權的商品 Google Sheet 中同步的料號、名稱、車種、價格與圖片欄位等商品資料。

圖片功能使用 Google Drive 的 drive.file 範圍，不要求讀取整個雲端硬碟；不要求存取 Gmail、Google 聯絡人或行事曆。Google 的授權畫面可能列出此權限允許的查看、編輯、建立與刪除操作；目前圖片流程用於建立圖片、查找本應用程式的圖片及設定連結讀取權限。

2. 使用目的

資料僅用於提供商品圖片上傳、Google Drive 圖片儲存、Google Sheet 商品同步、避免重複上傳、錯誤排查及系統維護。OAuth 憑證用於管理者離線時持續執行已授權的同步，不要求或保存 Google 帳戶密碼。

3. 圖片分享與第三方服務

為使試算表可載入圖片，應用程式上傳的商品圖片會在 Google Drive 設為「知道連結的任何人」可讀取，且不主動開啟檔案搜尋曝光。取得連結的人仍可查看或下載圖片；這些圖片不應包含私人或機密資訊。

圖片及商品欄位會傳送至 Google Drive／Google Sheets 以提供上述功能。FAR 的應用程式資料、上傳圖片及背景授權設定存放於 Oracle Cloud 主機。出貨單及廠商名單不會因本介紹頁或本政策公開而公開。

本應用程式不出售 Google 使用者資料，不將其用於廣告、信用評估，或訓練通用人工智慧模型。Google API 資料的使用與轉移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

4. 保存與保護

FAR 採用私人網路限制管理介面存取；授權設定以受限檔案權限保存在伺服器，並用於透過 HTTPS 與 Google 通訊。管理者僅為提供服務、排查問題及處理刪除要求而存取相關資料。

商品圖片、檔案對應資料及授權設定會保留至管理者刪除或不再需要時。刪除 FAR 商品紀錄目前不會自動刪除 Google Drive 圖片或其他備份；請另外提出圖片及相關資料刪除要求。既有備份可能依系統備份輪替方式保留一段時間。

5. 撤銷授權與刪除資料

你可隨時前往 Google 帳戶的第三方應用程式連線設定，撤銷「FAR 商品圖片同步」的存取權。撤銷後，新的圖片同步可能停止；已建立的圖片、連結分享設定及試算表內容不會自動刪除或轉為私人。

若要刪除 FAR 保存的圖片、對應資料或授權憑證，或要求協助撤下已分享圖片，請寄信至 iwant2b1234@gmail.com，說明欲處理的圖片或紀錄。請勿在信件中提供密碼或授權憑證。管理者會核對請求並協助處理。

6. 政策更新

若資料使用方式調整，會更新本頁及上方更新日期。新增用途或需要額外 Google 權限時，會依適用要求另行取得同意。
